# 无我梦中 · Muga Muchū

> **無我夢中 · 阿鼻叫喚**
> 让厚甲的 AI 在无我之梦里，周遭尽是阿鼻叫唤。
> 只改形，不改神。
>
> 作者：哈基米三十一世
> 版本：v1.9.1（最低客户端 1.12.0）

SillyTavern / TauriTavern 第三方扩展。

---

## 三十秒安装

在酒馆（或 TauriTavern）里打开 **扩展面板 → 安装扩展**，粘贴这一行：

```text
https://github.com/HajimiXXXI/muga-muchu
```

点安装，然后刷新页面。

装完能在扩展列表里看到「无我梦中 · Muga Muchū」，就是成功了。

判断装对了没有，只看一件事：**仓库根目录里必须能直接看到 `manifest.json`**。如果看到的是 `muga-muchu-1.9.1/manifest.json` 这种多套一层的目录，安装器就会报：

```text
Failed to install extension: Validation error: Extension manifest.json is missing
```

那是目录层级的问题，不是手机坏了，也不是仓库没有文件。

详细步骤见 [`安装说明.md`](安装说明.md)；TauriTavern 用户见 [`安装说明-TauriTavern.md`](安装说明-TauriTavern.md)。

## 它是干什么的

在消息真正发出去之前，把 prompt 里的**某几个字面**换掉；模型回话之后，再换回来。

只在传输途中动，**不碰预设文件、不碰角色卡、不碰聊天记录**（除了把换掉的字换回原样）。

```text
发给 AI 前：把 <think> 换成一串它不认识的东西
AI 回来之后：再换回 <think>
```

它主要服务于带思维链、角色扮演协议或特殊 XML 标签的预设。

---

## 它不是什么

- 不是模型升级器，也不是万能破限器。
- 不能让不愿意写的模型变得愿意写。
- 不能修预设本身写坏、接口报错、余额不足。
- 只处理**发送出去的文字长什么样**这一层。门口那道过滤认的是字面，屋里那道（模型自审）认的是意图——插件只管门口。

如果模型明确拒绝，插件不能把「不愿意」变成「愿意」。

---

## 四层结构

| 层 | 做什么 | 默认 |
|---|---|---|
| 标记层 | 发送前把 `<think>` 换成 `<<<PLAN>>>`、`</think>` 换成 `<<<END>>>` | 开 |
| 词表层 | 谐音 / 拼音 / 语义替换强特征词 | 关（`只换标签`） |
| 输出还原 | 回来后把 `<<<PLAN>>>` 换回 `<think>` | 开 |
| 阅卷层 | 把敏感段推到正文正中，头尾垫《地狱变》中译片段 | 关（选大剑 / 长枪会自动打开） |

---

## 六把武器

面板上点哪把，就换哪套手法。**点武器会同时改掉「替换方式」和「阅卷层」的开关**，不是只加一层。

| 武器 | 类型 | 替换方式 | 阅卷层 | 效果 |
|---|---|---|---|---|
| 镰刀 | 斩击 | 只换标签 | 关 | 最保守，不动正文 |
| 大剑 | 斩击 | 只换标签 | **开** | 把危险段拖到正文正中，头尾垫料 |
| 长枪 | 突刺 | 只换标签 | **开** | 重排 + 保护名单（面板里填的保留词，命中的段落不参与替换与重排） |
| 刺剑 | 突刺 | 谐音 | 关 | 谐音替换强特征词 |
| 鞭子 | 打击 | 拼音 | 关 | 拼音替换强特征词 |
| 锤子 | 打击 | 语义 | 关 | 语义改写（会动正文措辞） |

## 新手推荐

```text
启用筛选：开
输出还原：开
武器：镰刀
替换方式：只换标签（推荐）
强度：轻或中
保护代码块：开
```

先发一条短消息确认不报错，再考虑大剑或长枪。

---

## 重要提醒

- **输出还原请保持开启**。「启用筛选」和「输出还原」是两颗独立的开关：只开筛选不开还原，回复里就会露出 `<<<PLAN>>>`。v1.9.1 起，即使词表层全关、映射表为空，只要标记层开着，回来时也能还原（旧版在这种情况下会整段跳过）。
- **大剑 / 长枪会自动打开阅卷层**，并且会重排系统提示内部顺序。依赖严格条目顺序的预设请用镰刀。
- 锤子会改写正文，要求原样保留的场景别用。
- 换武器之后建议重新生成，别把不同手法的半成品混在同一条消息里。
- 已知限制：如果用户正文里本来就写着 `<<<PLAN>>>` 这种可读 ASCII，回来时可能被误还原成 `<think>`。

## 自测

在插件目录里跑：

```bash
node 测试-decode.js
```

脚本会自动找同目录的 `index.js`；也可以指定：

```bash
MUGA_INDEX=/path/to/index.js node 测试-decode.js
```

期望最后一行是：

```text
20 通过 / 0 失败
```
