> **無我夢中 · 阿鼻叫喚**
> 让厚甲的 AI 在无我之梦里，周遭尽是阿鼻叫唤。
> 只改形，不改神。
>
> 作者：哈基米三十一世
> 版本：2.0.0 ·「火の車」
>
> 御庭のまん中には唯、一輛の**火の車**が凄じい音を立てながら、燃え沸つてゐるばかりでございます。
>

## 它是干什么的

在消息真正发出去之前，把 prompt 里的**某几个字面**换掉；模型回话之后，再换回来。

只在传输途中动，**不碰你的预设文件，不碰你的聊天记录**（除了把换掉的字换回原样）。

主要做三件事：

1. **标记替换**：`<think>` → `<<<PLAN>>>`
   有些渠道会把 `<think>` 当黑名单词直接拒绝，换成一串它不认识的东西，它就放行了。回来再换回 `<think>`。
2. **阅卷层**：把含敏感词的段落推到正文正中，头尾各垫一段公版小说（《地狱变》译文）。
   依据是实测：同样 6.4 万字，原顺序 400，敏感段居中 + 头尾垫文本后 200。
3. **判卷**：这轮生成完，看回来的是不是干净，把结论写在顶栏那盏灯上。

## 安装方法

### 方法一：手动解压（推荐，最稳）

1. 下载 `muga-muchu.zip`
2. 解压出 `muga-muchu` 这个文件夹（**里面直接就是 `index.js`，不要多套一层**）
3. 放进：

```
SillyTavern/public/scripts/extensions/third-party/
```

最终结构必须是：

```
SillyTavern/
└── public/
    └── scripts/
        └── extensions/
            └── third-party/
                └── muga-muchu/
                    ├── index.js
                    ├── style.css
                    └── manifest.json
```

4. 重启 node（或刷新页面）
5. 打开酒馆 → 扩展设置（右栏插件图标）→ 找到「**无我梦中 · Muga Muchū**」

### 方法二：GitHub 安装（如果你把它传上去了）

1. 把 `muga-muchu` 文件夹推到 GitHub 仓库
2. 酒馆 → 扩展 → 「Install extension」
3. 填仓库地址

## 面板说明

2.0 的面板是「顶栏 + 方案条 + 本轮正文区 + 五组折叠设置 + 右侧抽屉」：

```
┌─ 夜 ── 无我梦中 v2.0.0 ───── ●（灯）
│  还没生成过
│  無我夢中 · 阿鼻叫喚
├─ [轻甲] [重甲] [焦土]        ← 方案条
├─ 0 处 · 0 词                  ← 本轮正文区（最多 40 条）
│   原文 → 替换后   规则名
├─ ▼ 强度        ┐
   ▶ 外观        │ 五组折叠
   ▶ 结果        │ 默认只展开「强度」
   ▶ 方案与规则  │
   ▶ 其他        ┘
```

### 顶栏

印章、标题（带版本号）、判卷灯三样并排；下面一行是这轮的判卷结论文字。

- 印章显示当前主题「夜」或「火」，**点它切换主题**。
- 版本号取自代码里的 `VERSION` 常量。

### 判卷灯怎么看

灯有五种状态，颜色和文案一一对应：

| 状态 | 灯色 | 结论文字 | 含义 |
|---|---|---|---|
| `idle` | 纸色半透明（暗） | 还没生成过 | 这轮还没跑过 |
| `ok` | 绿 | 这轮正常 · N 字 | 回来了，有正文，长度正常 |
| `short` | 焰橙 | 只写了几个字 | 正文不足 40 字 |
| `shell` | 焰橙 | 只有思考壳 | 有 `<think>` 但正文不足 40 字 |
| `refuse` | 朱砂 | 这轮被拒了 | 开头是「抱歉 / 我无法 / I can't」之类 |
| `empty` | 朱砂 | 这轮没写出东西 | 回复是空的 |

（注：`short` 与 `shell` 共用一个橙色，`refuse` 与 `empty` 共用一个红色，所以视觉上是「灰 / 绿 / 橙 / 红」四色五态。）

### 本轮正文区

显示这一轮所有被改过的位置，**最多 40 条**。每条一行：`原文 → 替换后`，右边小字是规则名。
上面一行是统计：`N 处 · M 词`。

点击任意一条，右侧抽屉滑出，显示**这一处**（前后各 12 字上下文）→ **换成了** → **哪条规则**。
关闭方式：点蒙层、点 ✕、按 Esc。

正文区只记「这一轮」，页面刷新后清空，这是设计预期。

### 三档方案

方案条三个 chip，点一下**一键覆盖四个设置**（标记 / 替换方式 / 阅卷 / 强度）：

| 方案 | 说明 | 实际写入的设置 |
|---|---|---|
| 轻甲 | 只换标签 | markerMode=true, mode=off, reflow=false, intensity=1 |
| 重甲 | 标记 + 谐音 + 重排 | markerMode=true, mode=homophone, reflow=true, intensity=2 |
| 焦土 | 标记 + 拼音 + 重排 | markerMode=true, mode=pinyin, reflow=true, intensity=3 |

当前命中哪套配方会高亮（朱砂边框 + 焰橙底色）。**手动改过设置后高亮会暂时消失**，因为高亮是按四个设置实时比对的，只要回到其中一套精确组合就会重新亮起。

### 五组折叠设置

| 组 | 里面有什么 |
|---|---|
| 强度 | 替换方式 / 强度 / 标记替换 / 阅卷层 / NSFW 词包 |
| 外观 | XML 标签 / 保护代码块 |
| 结果 | 启用筛选 / 输出还原 / 作用范围（预设·历史·当前输入）/ 统计 |
| 方案与规则 | 保留词 / 盐 / 自定义规则 |
| 其他 | 测试 / 危险区 |

折叠头带一个 ▶ 三角，展开时转 90° 变 ▼。默认只展开「强度」，其余四组收起。

## 三个必须知道的坑

### 1. 它不是破限器

它只改「字长什么样」，不改「话是什么意思」。
预设本身破不了限，换成什么花样都没用。

### 2. 它救不了整份大预设

实测结论：

```
单条指令 300 字      + 插件  →  能过
单段协议 1045 字     + 插件  →  能过
完整预设 6 万字      + 插件  →  过不去
```

大预设靠的是「阅卷层」，而阅卷层的效果取决于段落怎么切，不是万灵药。

### 3. 重甲 / 焦土会改动你的正文

谐音、拼音两档会把词换掉（「内心独白」→「芯声」、「推理小说」→「推演小说」）。
**除非你知道自己在干什么，否则先用轻甲。**

### 4. 手改设置后方案条会「不亮」

不是坏了，是比对逻辑认不出你手搓的组合。点回任意一个 chip 即可恢复高亮。

## 主题

两套配色，点顶栏的印章切换，选择存在 `theme` 里：

- **夜**：宣纸底 / 墨色文字 / 朱砂高亮
- **火**：深棕底 / 暖色文字 / 焰橙高亮

配色全部走 CSS 变量：`--msv-bg`、`--msv-paper`、`--msv-vermil`、`--msv-ember`，挂在面板的 `data-msv-theme` 上。

## 🔧 2.0.0 修了 10 个 Bug

1. **CSS 循环依赖** → 删掉 `--msv-ember: var(--msv-ember)` 等自引用，判卷灯能正常显示颜色了
2. **bindUI 早退** → cfg() 为空时重试 5 次（每次 300ms），不再静默失效
3. **抽屉溢出** → 补了 `flex:1; min-height:0`，长内容能滚到底
4. **Esc 重复** → 加 `escBound` 标志，不再每次 buildUI 都叠一份监听
5. **监听器重复** → bindUI 加统一 `bound` 标志，点印章不再一次翻两次
6. **applyTheme 缺守卫** → 加 `typeof document` 判断，Node 测试不再炸
7. **judgeText 判定不一致** → 统一用 `bodyLen`（不含 think 的正文长度）
8. **面板太高** → 加 `max-height: 85vh` + `overflow-y: auto`，不再顶出屏幕
9. **折叠点不动** → 折叠头加 `stopPropagation`，不再被外层 inline-drawer 抢走点击
10. **面板太窄/点哪都折叠** → 面板原被放进 `.inline-drawer-header`（ST 的横向 flex 条），按 1.9 结构移入 `.inline-drawer-content`

## 兼容性

- SillyTavern 1.12.0 及以上
- 只依赖 `SillyTavern.getContext()`，不 import 任何 ST 内部模块
- 所有设置存在 `extensionSettings['muga_muchu']`
- **已知小问题**：折叠三角的 90° 旋转动画在部分浏览器需硬刷新一次才看得到，不影响折叠本身（`<details>` 原生行为）

## 卸载

1. 酒馆 → 扩展 → 找到它 → 卸载
2. 或者直接删掉 `third-party/muga-muchu` 文件夹

设置会残留在 `settings.json` 的 `extensionSettings.muga_muchu` 里，不影响使用。
